
# Graduation Project: Cross-Domain Turkish Sentiment Analysis Using Transformer Models

## Project Overview

This project investigates the cross-domain generalization capabilities of Transformer-based sentiment analysis models for Turkish. The objective is to evaluate how well sentiment classification models trained on one domain perform when applied to different domains.

## Team

## Supervisor

## Research Objectives

- Investigate cross-domain generalization in Turkish sentiment analysis.
- Compare in-domain and cross-domain performance.
- Analyze the effect of domain characteristics on model performance.
- Compare Turkish-specific and multilingual Transformer models.

## Target Domains

- Product Reviews
- Movie Reviews
- Tweets

## Models

- BERTurk
- XLM-RoBERTa-base
- ModernBERT-TR-base

## Evaluation Metrics

- Macro F1-Score
- Accuracy
- Confusion Matrix
- Error Analysis
